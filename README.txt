MONOFONE — SITE V1
===================

Esta é uma primeira versão estática, pronta para hospedagem gratuita.

Arquivos:
- index.html
- style.css
- script.js

IMPORTANTE:
O lettering oficial da MONOFONE foi mantido como ativo de marca a ser inserido,
em vez de redesenhá-lo. O texto atual "MONOFONE" funciona apenas como placeholder
visual. Substitua-o pelo arquivo oficial do lettering quando disponível.

Também devem ser substituídos:
- capa do lançamento
- links Spotify/YouTube/Instagram
- agenda
- e-mail de contato
- fotos da banda

Hospedagem gratuita:
Pode ser publicada em GitHub Pages ou Netlify.
